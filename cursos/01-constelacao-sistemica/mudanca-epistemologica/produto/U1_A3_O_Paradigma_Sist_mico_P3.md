[pertença] **Coleção Pertença (ebooks profundos `per-01` a `per-07`)** — a aula valida directamente o núcleo desta coleção: a ideia de que uma mudança num membro do sistema (quem saiu, quem ficou, quem carregou) reorganiza o sistema inteiro, incluindo quem fica responsável cedo demais ou quem mantém toda a gente ligada.
**Ideia concreta:** O ebook `per-04 A pessoa que ficou responsável cedo demais` pode ganhar um capítulo ou parágrafo âncora a partir do exemplo da aula (o filho que sai de casa e o que isso muda no casal e no sistema) — invertido: e quando quem sai não é o filho adulto, mas é a criança que teve de crescer para segurar o sistema? A lógica sistêmica da aula dá suporte conceptual directo a esse ângulo.

[pertença] **ebook fundador `ebook-02-herdaste` — O que herdaste sem saber** — a aula fundamenta que nenhum fenómeno ocorre de forma isolada e que o sistema familiar se reorganiza em cadeia; o que se herda invisìvelmente é exactamente o produto das transações não nomeadas do sistema.
**Ideia concreta:** Usar o princípio "uma mudança num aspecto do sistema promove mudança em todos os outros" como fio condutor de um capítulo sobre heranças sistémicas invisíveis — o que muda em ti quando alguém no teu sistema original muda (ou não muda).

Fechar no ciclo quebrado: *"Quando você muda, o sistema todo muda. É aí que o ciclo acaba em si."* CTA: GUARDAR. Hashtags: #acabaemmim #quebraciclos.

[pertença] **guia `guia-01-meu` — O que é meu, o que não é meu** e **`guia-07-teu` — O que é mesmo teu** — a aula valida que num sistema de dependência mútua é estruturalmente difícil distinguir o que pertence a cada elemento; essa confusão é sistêmica, não pessoal.
**Ideia concreta:** Introduzir no guia uma frase âncora que valide a dificuldade de forma sistêmica — *"Num sistema de dependência mútua, separar o que é teu do que é do sistema é um acto de clareza, não de egoísmo."* — para que a leitora não se culpe pela confusão, mas a compreenda como estrutural.

[oportunidade] **Novo:** mini-guia ou ebook *"Quando um muda, o sistema todo muda"* — para cuidadoras (mães, filhas mais velhas, profissionais de saúde) que estão a contemplar uma mudança pessoal significativa (sair de um papel, dizer não, mudar de carreira) mas sentem o peso de "desestabilizar" os outros. A aula oferece o fundamento sistêmico exacto: a mudança num elemento é inevitavelmente uma mudança no sistema, e isso não é destruição — é reorganização. Público: mulheres que se travam para não "estragar" o equilíbrio do sistema. Porquê agora: este é o medo não nomeado por baixo de muitas das coleções (FreeMe Mãe, Força, Trabalho e Vocação) e não existe ainda um produto que o enderece directamente com linguagem sistêmica acessível.
