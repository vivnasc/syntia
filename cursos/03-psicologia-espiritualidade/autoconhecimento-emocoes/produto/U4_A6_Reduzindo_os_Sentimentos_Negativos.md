# NOTAS

1. **"Célio" / livro *Florescer*:** a transcrição usa o nome "Célio" como autor de *Florescer*. Com grande probabilidade trata-se de **Martin Seligman** (o livro *Flourish* / *Florescer* é da sua autoria). O nome foi transcrito de forma incorrecta. Recomendo verificar no material da apostila antes de usar em avaliação.

2. **"Série de Manhã" / "Série":** ao longo da aula, o investigador referenciado para os dados das três bênçãos e da gratidão é chamado de "Série de Manhã" e depois apenas "Série". É quase certamente uma deturpação de **Seligman** na transcrição áudio. Confirmar na apostila.

3. **"Sabres" / "Savoring":** a transcrição ora usa "saboring", ora "saving", ora "sabres". Trata-se sempre do mesmo conceito — **savoring** — mal captado pelo sistema de transcrição.

4. **Partes truncadas:** várias frases estão visivelmente cortadas («in benef para as pessoas com hipertens», «ajudar a mant sob controle», «conversar com algu», «uma situa favor intensifica o saving», «Ent voc revive», etc.). O conteúdo inferível é consistente com o contexto, mas os dados exactos dessas passagens (nomeadamente os benefícios completos do mindfulness para a hipertensão) não podem ser citados com segurança.

5. **"Saborear" vs. "Savoring":** a aula usa os dois termos de forma intercambiável. Para efeitos de avaliação, o termo técnico é **savoring**; a definição exacta citável é a que aparece na transcrição: «pensamentos e comportamentos capazes de generalizar, intensificar e prolongar situações de prazer».
