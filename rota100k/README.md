# ROTA100K

Espaço próprio, fora de `cursos/` (que é a pós-graduação). Aqui vive o
conhecimento de negócio: criação de conteúdo, audiência, crescimento.

Está no mesmo patamar da `disciplina-partilhada`: é uma raiz que a ponte
lê, por isso tudo o que entra aqui chega ao `viviannepag` (conceitos em
`lib/infografico/cursos.ts` e saber integral em `saber/`).

Estrutura (criada pelo processamento, não à mão):

    rota100k/
      transcricoes/   texto bruto das aulas
      sinteses/       Bloco A + B
      produto/        Bloco C — o que alimenta os produtos
      resumos/
      objetivos/
      _material/      PDFs de apoio
